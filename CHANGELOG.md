# Changelog

## v0.4.0-beta

- UE4SS mod automatically starts the bundled helper when the game loads.
- Helper exits and clears activity after the game process closes.
- PT-BR and English activity text.
- Eleven recognized locations, all four difficulty labels, health percentage and session time.
- Menu/map/customization artwork and shopping/save-trigger activity states.
- Player package includes the runtime; no separate Node.js installation is needed.

Source publication documents this existing release. It does not change the mod's runtime behavior.
